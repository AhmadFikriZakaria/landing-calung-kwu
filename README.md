# Landing Page Mandiri Laras Production

Landing page statis (HTML, CSS, JS) untuk promosi calung dan angklung bambu wulung dari Desa Kemutug Lor, Baturraden. Proyek KWU Kelompok 16, Informatika Unsoed.

**Status: versi progres.** Data produk dan harga adalah data uji dari wawancara 16 September 2026, dan nomor WhatsApp masih nomor uji.

## Isi

- `index.html` beranda, `profil.html` profil dan proses, `katalog.html` katalog dengan filter kategori, `produk-1.html` sampai `produk-6.html` detail produk.
- `assets/app.css` gaya (Tailwind hasil kompilasi), `assets/site.js` tema gelap/terang, menu mobile, filter, animasi muncul.
- Tanpa framework, tanpa database, tanpa admin. Bisa dibuka langsung dari file atau lewat GitHub Pages.

## Mengganti nomor WhatsApp

Cari `6280000000000` di seluruh file `.html`, ganti dengan nomor asli berformat `62...`.

## Catatan

Versi penuh dengan halaman admin dan database ada di repo terpisah. Halaman ini tidak diindeks mesin pencari (`noindex`).
